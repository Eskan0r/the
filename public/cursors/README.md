windows-arrow.png is the 32 x 32 arrow extracted from the locally configured
Windows cursor file, C:\Windows\Cursors\aero_arrow.cur. The hotspot is (0, 0).
The PNG preserves the source bitmap's color and transparency.

The pond uses this same asset for the CSS cursor and canvas cursor so pickup
does not change the artwork. This is a local reference, not automatic detection
of each visitor's system cursor theme or accessibility settings.
